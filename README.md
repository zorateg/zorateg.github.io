# Рацион

Небольшое адаптивное веб-приложение на русском языке: рассчитывает ориентир суточной калорийности и предлагает три блюда на день. Проект работает без сборки и сторонних библиотек.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Возможности

- Расчёт основного обмена по формуле Миффлина — Сан Жеора и дневной цели с учётом активности и выбранной цели.
- Проверка диапазонов и точности введённых параметров.
- Подбор завтрака, обеда и ужина; каждое блюдо можно заменить на следующий вариант.
- Сумма калорий меню и наглядное сравнение с дневной целью.
- Адаптивная вёрстка, клавиатурная навигация и поддержка уменьшения анимации.

Расчёты и калорийность блюд приблизительны и не заменяют консультацию врача или диетолога. Фотографии блюд загружаются с Unsplash; параметры пользователя на сервер не отправляются.
